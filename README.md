# DegsLand – Website giới thiệu bất động sản

## 1. Giới thiệu dự án

**DegsLand** là website tĩnh giới thiệu bất động sản, được xây dựng nhằm cung cấp thông tin về các dự án, lợi thế, quy trình tư vấn và thông tin liên hệ tới khách hàng có nhu cầu tìm hiểu về bất động sản.

Dự án được xây dựng bằng HTML5 và CSS3, tập trung vào việc thiết kế giao diện trực quan, dễ sử dụng, bố cục rõ ràng và tương thích với các thiết bị có kích thước màn hình khác nhau.

## 2. Mục tiêu dự án

- Xây dựng website giới thiệu bất động sản với giao diện chuyên nghiệp.
- Cung cấp thông tin về các dự án bất động sản.
- Giúp người dùng dễ dàng tìm hiểu thông tin và liên hệ tư vấn.
- Rèn luyện kỹ năng xây dựng website bằng HTML5 và CSS3.
- Áp dụng kiến thức về bố cục, responsive design và triển khai website tĩnh.

## 3. Công nghệ sử dụng

| Công nghệ | Mục đích |
|---|---|
| HTML5 | Xây dựng cấu trúc và nội dung website |
| CSS3 | Thiết kế giao diện, bố cục và hiệu ứng hiển thị |
| Flexbox | Xây dựng bố cục linh hoạt |
| CSS Grid | Bố trí các thẻ dự án |
| Responsive Design | Tối ưu giao diện trên nhiều kích thước màn hình |
| Visual Studio Code | Môi trường phát triển |
| Live Server | Chạy website cục bộ |
| Git/GitHub | Quản lý và lưu trữ mã nguồn (nếu đã khởi tạo repository) |
| GitHub Pages | Triển khai website tĩnh công khai |

## 4. Các chức năng và khu vực chính

- **Trang chủ:** Giới thiệu tổng quan về DegsLand.
- **Giới thiệu:** Cung cấp thông tin về website và định hướng hoạt động.
- **Dự án bất động sản:** Hiển thị các dự án với hình ảnh và thông tin giới thiệu.
- **Lợi thế:** Trình bày các điểm nổi bật.
- **Quy trình:** Giới thiệu quy trình tư vấn và hỗ trợ khách hàng.
- **Liên hệ:** Cung cấp thông tin liên hệ và biểu mẫu liên hệ.
- **Điều hướng:** Cho phép người dùng di chuyển đến các khu vực tương ứng.
- **Responsive:** Điều chỉnh giao diện phù hợp với desktop, tablet và mobile.

## 6. Hướng dẫn chạy website

### Yêu cầu

- Windows, macOS hoặc Linux.
- Visual Studio Code.
- Trình duyệt Google Chrome hoặc trình duyệt tương thích.
- Extension Live Server trong Visual Studio Code.

### Các bước thực hiện

1. Tải hoặc clone repository DegsLand về máy.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Cài đặt extension Live Server nếu chưa có.
4. Mở file `index.html`.
5. Nhấn chuột phải và chọn `Open with Live Server`.
6. Website sẽ được mở trên trình duyệt.

## 7. Kiểm thử website

Website được kiểm thử nhằm đánh giá khả năng hoạt động của các thành phần giao diện và khả năng hiển thị trên các kích thước màn hình khác nhau.

Các nội dung kiểm thử bao gồm:

- Kiểm tra tải trang chủ.
- Kiểm tra logo và điều hướng.
- Kiểm tra nội dung các khu vực.
- Kiểm tra danh sách dự án.
- Kiểm tra biểu mẫu liên hệ.
- Kiểm tra hình ảnh.
- Kiểm tra footer.
- Kiểm tra giao diện trên desktop, tablet và mobile.

Chi tiết các trường hợp kiểm thử được ghi trong file:

`docs/test-cases/test-cases.md`

Minh chứng kiểm thử được lưu trong thư mục:

`docs/screenshots/`
